Student Career & Skill Gap Analyzer

A beginner-friendly Python project that helps students compare their current skills with the skills listed for a selected career.

Features

- Choose a career path.
- Select skills you already have.
- View matched and missing skills.
- See a skill-match percentage.
- Get suggested learning resources and project ideas.
- Download a simple analysis report.

Technologies Used

- Python
- Streamlit
- Pandas

How to Run

1. Install the required packages:
   python -m pip install streamlit pandas
2. Run the app:
   python -m streamlit run app.py

Note

This is an educational prototype. Career skill requirements and recommendations are sample data and should be checked against current job descriptions and learning resources.
